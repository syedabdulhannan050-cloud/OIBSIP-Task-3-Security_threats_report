###  Topics Covered

#### 1. Distributed Denial-of-Service (DDoS)
A DDoS attack attempts to overwhelm a server, website, or network with traffic from multiple sources, making the service slow or unavailable.

**Prevention and mitigation:**
- Use firewalls and DDoS protection services.
- Monitor unusual traffic patterns.
- Apply rate limiting and traffic filtering.

#### 2. Man-in-the-Middle (MITM)
A MITM attack occurs when an attacker secretly intercepts or potentially modifies communication between two parties.

**Prevention:**
- Use HTTPS and properly validated TLS certificates.
- Avoid untrusted public Wi-Fi for sensitive activities.
- Use a trusted VPN when appropriate.
- Keep devices and applications updated.

#### 3. IP Spoofing
IP spoofing occurs when an attacker forges the source IP address in network packets to disguise their origin or impersonate another address.

**Prevention:**
- Implement ingress and egress packet filtering.
- Use network security controls and monitoring.
- Apply appropriate authentication and access controls.
- Do not rely on source IP addresses alone for authentication.
